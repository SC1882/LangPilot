# Changelog

All notable changes to LangPilot are documented here.

## 2.0.0-beta.3

- Added local export/import for learned word pairs.
- Import now merges learning data instead of replacing stronger existing corrections.
- Updated README and privacy documentation to describe export/import behavior.
- Bumped app bundle version to `2.0.0-beta.3`.

## 2.0.0-beta.2

- Added local spelling suggestions near the text cursor.
- Added Tab to accept suggestions and Esc to dismiss them.
- Added native settings UI with General, Spelling, Learning, and Privacy tabs.
- Added configurable suggestion duration.
- Added sound notification for keyboard-layout changes.
- Added launch-at-login support.
- Added per-application exclusions.
- Improved privacy documentation.

## 2.0.0-beta

- Initial public beta release.
- Added automatic keyboard-layout detection and correction.
- Added Russian, English, and German support.
- Added local learning from manual corrections and undo actions.
- Added secure-field protection for password fields.
- Added DMG packaging and GitHub release artifacts.
